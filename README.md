# Reputation DAO Contract

A governance contract that assigns and tracks reputation scores for members,
enabling merit-based governance and participation weighting.

## Key Functions
- `add-reputation` — Increase a member’s reputation score
- `reduce-reputation` — Decrease reputation due to penalties or inactivity
- `get-reputation` — Retrieve a member’s reputation score
- `is-member` — Check DAO membership status
- `reputation-weight` — Calculate governance weight based on reputation

Designed for DAOs that reward contribution, discourage spam, and enable merit-driven governance.
